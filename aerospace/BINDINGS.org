#+TITLE: AeroSpace Bindings
#+STARTUP: showall

Generated by ~scripts/aerospace-cheatsheet~ from the running AeroSpace. Do not edit by hand.

Caps lock is the hyper key, shown here as ~caps-~. Tapped alone it sends Escape.

* Go to workspace
Switches workspace and launches the app if it is not running.

| Key      | Does                         |
|----------+------------------------------|
| ~caps-c~ | workspace C  (Claude)        |
| ~caps-e~ | workspace E  (Emacs)         |
| ~caps-m~ | workspace M  (Messages)      |
| ~caps-o~ | workspace O  (Obsidian)      |
| ~caps-s~ | workspace S  (Slack)         |
| ~caps-t~ | workspace T  (Ghostty)       |
| ~caps-v~ | workspace V  (zoom.us)       |
| ~caps-w~ | workspace W  (Google Chrome) |

* Send window to workspace
Moves the focused window and follows it there.

| Key           | Does           |
|---------------+----------------|
| ~alt-shift-c~ | -> workspace C |
| ~alt-shift-e~ | -> workspace E |
| ~alt-shift-m~ | -> workspace M |
| ~alt-shift-o~ | -> workspace O |
| ~alt-shift-s~ | -> workspace S |
| ~alt-shift-t~ | -> workspace T |
| ~alt-shift-v~ | -> workspace V |
| ~alt-shift-w~ | -> workspace W |

* Focus
Directional focus needs tiled windows; cycling works on floating ones too.

| Key      | Does                                     |
|----------+------------------------------------------|
| ~caps-'~ | back to the last window you were on      |
| ~caps-h~ | focus left                               |
| ~caps-j~ | focus down                               |
| ~caps-k~ | focus up                                 |
| ~caps-l~ | focus right                              |
| ~caps-n~ | next window in this workspace, wraps     |
| ~caps-p~ | previous window in this workspace, wraps |

* Move and resize

| ~alt-shift-h~ | move left        |
| ~alt-shift-j~ | move down        |
| ~alt-shift-k~ | move up          |
| ~alt-shift-l~ | move right       |

* Modes
Service mode runs one key then returns to normal on its own.

| Key      | Does               |
|----------+--------------------|
| ~caps-;~ | enter service mode |
| ~caps-r~ | enter resize mode  |

* Other
| Key             | Does                                         |
|-----------------+----------------------------------------------|
| ~caps-tab~      | workspace-back-and-forth                     |
| ~alt-shift-tab~ | move-workspace-to-monitor --wrap-around next |

* Service mode
Press ~caps-;~ then one of these. It returns to normal mode on its own.

| Key          | Does                          |
|--------------+-------------------------------|
| ~backspace~  | close-all-windows-but-current |
| ~down~       | volume down                   |
| ~esc~        | reload-config                 |
| ~f~          | layout floating tiling        |
| ~r~          | flatten-workspace-tree        |
| ~shift-down~ | volume set 0                  |
| ~up~         | volume up                     |
